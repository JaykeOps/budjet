# Every change survives a sync merge

budjet never talks to a sync service, but people will edit the same Budget on two devices while offline (a Transaction added on a phone, an Assignment changed on a laptop) and let the sync service merge the Data Folder later. We promise that every change from every device survives that merge with no "pick one copy" conflict, and that when two devices edit the same thing, the most recent edit wins. Keeping the Budget as one file that is rewritten on every change would be simpler, but a sync service can only keep one copy of a file both devices changed, so one device's work would be silently lost. The promise therefore fixes how the Data Folder is laid out: each change is written as its own small record, and the Budget is read by combining them. Changing this later means migrating every user's Data Folder.
